JSON Web Key Set — non-production

This host serves a JSON Web Key Set used to verify signed client assertions for a SMART Backend Services FHIR integration. Non-production / sandbox use only.

Key set: jwks-nonprod.json

A JWKS contains public key material only — the modulus and exponent of an RSA public key. It is intended to be publicly readable; that is how the verifying party fetches it. No private key, credential, or protected health information is published here, and nothing on this host provides access to any system.
